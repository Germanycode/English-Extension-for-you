Core Concepts

Git is the local tool. GitHub is the online home for your code.

Local Repository

Your project folder plus its saved history. This project folder is already a Git repository.

Save point Commit

A named checkpoint. Good commits are small, clear, and easy to understand later.

Online copy Remote

The GitHub repository. In this project it is named origin.

First-Time Setup

Do this once on a new computer so Git knows who is creating commits.

Install Git

Download Git for Windows, then restart PowerShell or your editor terminal.

Check Git
git --version

Set your identity

Use the same name and email you want shown on GitHub commits.

Configure Git
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Connect GitHub

Sign in on GitHub. GitHub CLI is optional, but useful for pull requests and authentication.

Optional GitHub CLI
gh auth login
gh auth status

Branches and Pull Requests

A branch lets you work without disturbing the main project line. A pull request is where you review and merge that work.

Feature branch Use a branch for new work

Branches make it easier to test, review, and undo one idea without mixing it with everything else.

Create branch
git switch -c feature/short-description
Pull request Ask GitHub to compare branches

After pushing a branch, open a pull request on GitHub and compare it with master.

Push branch
git push -u origin feature/short-description

Protect API Keys

Secrets do not belong in GitHub. Treat API keys like passwords.

  • Keep real API keys in local browser storage, environment files, or a private backend.
  • Never paste a real key into JavaScript, HTML, screenshots, logs, or documentation.
  • Run git status and check file names before every commit.
  • Use .gitignore for local logs, generated screenshots, credentials, and environment files.
  • If a secret was pushed, rotate that key immediately and remove it from Git history.
!
Important for this extension

The Gemini key field in the options page is for your local browser. Do not hard-code your personal key into the project files.
